## Conseils

- Fenêtre de navigateur en 1440×900, zoom 100 %, mode clair.
- Cadrez sur le contenu utile — pas de barre d'onglets ni de favoris.
- Pour le terminal : thème sombre, police lisible, fenêtre large (≈120 colonnes).
- Une capture animée (GIF) du parcours « Prepare Run → double-clic → tests qui
  démarrent » aurait beaucoup d'impact en tête de README, si vous voulez aller
  plus loin.
